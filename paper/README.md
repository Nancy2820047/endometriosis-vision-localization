# Manuscript and publication figures

This directory contains the manuscript PDF, the complete IEEEtran LaTeX source, and the rendered figures used in the manuscript. The LaTeX source is configured to load figures from `figures/` and is ready to open as an Overleaf project after copying this directory's contents into a new Overleaf project.

The dataset, processed images, model checkpoints, and any credentials are intentionally excluded. Obtain GLENDA directly from its official source and comply with its terms of use.

Layout:

```text
paper/
├── endometriosis_vision_localization_paper.pdf
├── main.tex
└── figures/
```

The figure captions, manuscript values, and repository documentation refer to the same fixed five-fold out-of-fold evaluation.
