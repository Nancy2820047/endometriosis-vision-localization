# Manuscript assets

Place the manuscript source and the final, publication-quality figure files in this directory before public release. The dataset and model checkpoints must not be included.

Recommended layout:

```text
paper/
├── main.tex
├── references.bib
└── figures/
```

Use stable, descriptive filenames and ensure that figure captions, manuscript values, and repository documentation refer to the same fixed five-fold evaluation results.
